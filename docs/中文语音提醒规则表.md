# 中文语音提醒规则表

## 1. 总原则

- 只播报高价值信息
- 同类提醒必须节流
- 先提醒危险，再提醒环境
- 文案尽量短，不说专业术语

## 2. 提醒等级

### 2.1 静默

适用条件：

- 前方道路正常
- 没有明显高风险目标
- 可行驶区域稳定

策略：

- 不播报

### 2.2 提醒级

适用条件：

- 前方出现行人
- 前方出现动物
- 前方出现坑洼
- 前方道路变窄

推荐文案：

- `前方有行人，请注意`
- `前方有动物，请减速`
- `前方有坑洼，请避让`
- `前方道路变窄，请小心通行`

### 2.3 警告级

适用条件：

- 障碍物距离近
- 偏离道路明显
- 前方可通行区域急剧收缩

推荐文案：

- `注意，前方障碍物较近`
- `请回到道路中间`
- `前方通行空间不足，请减速`

## 3. 触发规则

### 3.1 行人

触发条件建议：

- 连续 `3` 帧检测稳定
- 位于画面中间偏下区域
- 与当前可行驶区域有重叠或接近

播报：

- `前方有行人，请注意`

### 3.2 动物

触发条件建议：

- 连续 `2` 帧检测稳定
- 位于前进方向附近

播报：

- `前方有动物，请减速`

说明：

- 动物优先级应略高于普通行人提醒，因为轨迹更不可预测

### 3.3 坑洼

触发条件建议：

- 位于当前主通行区域中部
- 面积超过设定阈值
- 连续 `2~3` 帧存在

播报：

- `前方有坑洼，请避让`

### 3.4 障碍物过近

触发条件建议：

- 检测框位于中心区域
- 连续稳定
- 近距估计达到警告阈值

播报：

- `注意，前方障碍物较近`

### 3.5 偏离道路

触发条件建议：

- 车辆中心参考点连续 `3~5` 帧落在主可行驶区域之外
- 或主可行驶区域明显偏到一侧

播报：

- `请回到道路中间`

### 3.6 道路变窄

触发条件建议：

- 前方主通行区域宽度连续下降
- 缩窄比例超过阈值
- 持续 `3` 帧以上

播报：

- `前方道路变窄，请小心通行`

## 4. 优先级

从高到低建议如下：

1. `障碍物过近 / 偏离道路`
2. `动物`
3. `行人`
4. `坑洼`
5. `道路变窄`

规则：

- 高优先级可以打断低优先级
- 低优先级不能打断高优先级

## 5. 节流规则

- 同一句提醒至少间隔 `4 秒`
- 同一类别不同目标，建议也共用节流
- 更高优先级新提醒可以在 `2 秒` 后打断低优先级
- 连续多帧触发时，不重复播报

## 6. 不建议播报的内容

- `道路正常`
- `检测中`
- `识别成功`
- `可通行区域较大`
- 频繁变化的小目标

原因：

- 这些信息对骑行帮助小
- 容易造成噪声和打扰

## 7. 当前推荐实现方式

- 分割结果用于判断：
  - 是否偏离道路
  - 前方道路是否变窄
- 检测结果用于判断：
  - 行人
  - 动物
  - 坑洼
  - 障碍物

## 8. 默认建议

- 默认语音开启
- 默认只播报提醒级和警告级
- 默认使用女声或温和男声普通话
- 语速不要太快
