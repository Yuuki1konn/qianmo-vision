# 系统架构说明

## 1. 总体流程

1. 数据层：公开数据 + 农村自采集数据。
2. 训练层：道路分割模型（U-Net / DeepLabV3+）+ 目标检测模型（YOLOv8）。
3. 导出层：PyTorch 权重导出为 ONNX / TFLite。
4. 端侧层：Android CameraX 实时采集 + TFLite 推理。
5. 交互层：掩码叠加显示 + 检测框 + TTS 语音告警。

## 2. 关键模块

- 数据预处理：尺寸统一、归一化、增强、划分。
- 分割推理：输出可行驶区域掩码。
- 检测推理：输出二轮车及障碍物框。
- 后处理：掩码阈值化/形态学操作、NMS 抑制重叠框。

## 3. 性能目标

- 端侧实时性：FPS >= 15。
- 分割精度：mIoU >= 0.70（农村测试集目标）。
- 检测精度：mAP@0.5 >= 0.75（核心类别目标）。
