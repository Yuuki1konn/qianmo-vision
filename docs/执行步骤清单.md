## 第 1 步：数据准备

1. 下载公开数据集（BDD100K / Cityscapes / KITTI / TWHD）。
2. 采集本地农村道路视频和图像。
3. 使用 LabelImg/LabelMe 完成检测与分割标注。

### 1.1.5 准备 Cityscapes / IDD 道路分割数据（推荐）

```powershell
python scripts/data/prepare_cityscapes_road_segmentation.py --root data/raw/cityscapes --output-dir data/processed/segmentation_cityscapes
python scripts/data/prepare_idd_road_segmentation.py --root data/raw/idd/IDD_20k_Segmentation_1 --output-dir data/processed/segmentation_idd_1
python scripts/data/prepare_idd_road_segmentation.py --root data/raw/idd/IDD_20k_Segmentation_2 --output-dir data/processed/segmentation_idd_2
```

- `Cityscapes`：默认仅使用 `road` 作为正类。
- `IDD`：默认使用 `road + drivable fallback` 作为正类。
- 当前项目实践中，`Cityscapes + IDD + BDD` 明显比 `RUGD` 更适合作为主分割监督。

- `segmentation_bdd_city_idd_refined.yaml`
  - 保守版 `strict`
  - `BDD` 只使用 `direct drivable`
- `segmentation_bdd_city_idd_relaxed.yaml`
  - 宽松版 `relaxed`
  - `BDD` 使用 `direct drivable + alternative drivable`

- 当前项目最终建议：
  - 主显示模型使用 `relaxed`
  - 安全边界参考保留 `strict`
