# 模型调研（分割 + 检测）

## 1. 道路分割模型对比

### 1.1 U-Net

- 优点：结构简单、对中小规模数据友好、训练稳定。
- 缺点：复杂场景的全局语义建模能力有限。
- 适用：农村场景数据量有限时，先做稳健基线。

### 1.2 DeepLabV3+

- 优点：ASPP 能获取多尺度上下文，复杂道路边界更强。
- 缺点：模型较重，端侧部署成本高于 U-Net。
- 适用：追求更高 mIoU 时作为第二阶段主力。

### 1.3 SegNet / PSPNet（备选）

- SegNet：轻量但细粒度边界可能略弱。
- PSPNet：场景理解强，但推理开销偏大。

## 2. 目标检测模型对比

### 2.1 YOLOv8

- 优点：工程成熟、训练和导出链路完整、端侧部署资料丰富。
- 缺点：小目标和极端光照下仍需增强数据与调参。
- 结论：作为当前项目主模型。

### 2.2 YOLOv5 / YOLOv11

- YOLOv5：生态成熟、稳定。
- YOLOv11：新版本通常精度更高，但需额外验证移动端兼容性。

### 2.3 RT-DETR

- 优点：精度潜力高。
- 缺点：推理速度压力更大，不利于端侧 FPS 目标。

## 3. 本项目推荐方案

- 分割：先 U-Net 作为基线，再尝试 DeepLabV3+。
- 检测：YOLOv8n 起步（速度优先），再评估 YOLOv8s（精度优先）。
- 导出：优先 TFLite INT8，验证与原模型的一致性。
