# 数据集推荐与下载优先级（农村二轮车道路识别）

## 目标

- 覆盖城市道路 + 非结构化/农村道路 + 二轮车/障碍物场景。
- 降低“训练数据与真实农村路况分布不一致”风险。

## A. 必下（第一批）

1. **BDD100K**（分割 + 检测 + 可行驶区域）
- 用途：道路可行驶区域分割、检测预训练。
- 优点：多天气/昼夜，任务类型齐全，含 drivable area 标注入口。
- 链接：
  - 下载入口：https://bdd-data.berkeley.edu/download.html
  - 官方主页：https://www.bdd100k.com/

2. **Cityscapes**（高质量语义分割基准）
- 用途：提高分割边界质量，作为精标“教师数据”。
- 优点：5,000 精细标注 + 20,000 粗标注，适合做分割预训练与对齐。
- 链接：
  - 官方主页：https://www.cityscapes-dataset.com/
  - 概览：https://www.cityscapes-dataset.com/dataset-overview/

3. **IDD（Indian Driving Dataset）**（非结构化交通）
- 用途：补充“混行、无规则、路边可行驶区域”等场景。
- 优点：含分割与检测子集，且场景更接近非结构化道路。
- 链接：
  - 官方主页：https://idd.insaan.iiit.ac.in/
  - 详情页：https://idd.insaan.iiit.ac.in/dataset/details/

## B. 建议下（第二批）

4. **KITTI Road**（经典道路检测评测）
- 用途：补充道路检测基准与对比实验。
- 链接：
  - 官方评测页：https://www.cvlibs.net/datasets/kitti/eval_road.php

5. **RUGD**（非结构化地面/越野语义）
- 用途：补充土路、草地、碎石等“农村/非铺装路面”语义。
- 链接：
  - 官方主页：https://rugd.vision/

6. **A2D2**（多传感器大规模补充）
- 用途：增强复杂道路视觉多样性，辅助鲁棒性训练。
- 链接：
  - 官方主页：https://www.a2d2.audi/en/
  - 数据集说明：https://www.a2d2.audi/en/dataset/

## C. 二轮车与安全专项（第三批）

7. **优先使用 IDD/BDD 中二轮车相关类**
- 原因：与你主任务（道路+检测）在同域，更容易迁移。

8. **头盔/骑乘行为专项数据（可选）**
- 若你要做“是否戴头盔”告警，再引入头盔专项数据集（如 HELMET/HelmetML 等），仅作为辅助分支，不建议替代主检测数据。

## 当前已下载数据的实际建议

- `TWHD`：建议只使用 `two_wheeler` 主类进入主检测集；`helmet/without_helmet` 先保留，后续再做头盔分支。
- `IDD 20K II`：建议从多边形标注中提取 `two_wheeler / pedestrian / animal / barrier / pothole / tricycle` 六类粗标签。
- `BDD100K`：你当前下载的是 `100k images + drivable maps`，适合分割；如果后面补下检测标签，再并入主检测集。

## 推荐配比（首版）

- 分割训练：`BDD100K:Cityscapes:IDD:RUGD:本地农村 = 25:15:20:10:30`
- 检测训练：`BDD100K:IDD:本地农村 = 30:25:45`
- 验证/测试：至少 **70% 使用本地农村独立采集数据**，并固定一套“夜间+雨后+逆光”安全集。

## 你现在就可以执行的下载顺序

1. 先下载 BDD100K + Cityscapes + IDD。
2. 再补 KITTI Road + RUGD。
3. 最后根据功能需要补头盔专项。

## 安全声明（重要）

- 任何视觉模型都**不能保证“绝对行驶安全”**。
- 可实现的是：通过更全面数据覆盖、保守阈值、失效降级策略、实地回归测试，显著降低风险。
- 在部署阶段，务必加入：低置信度降级提示、夜间/雨雾限速提醒、危险目标高召回优先策略。
