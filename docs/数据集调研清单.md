# 数据集调研清单（道路分割 + 二轮车检测）

## 1. BDD100K

- 任务：可行驶区域分割、车道线、检测、多任务。
- 规模：10 万段行车视频切帧，覆盖多天气和昼夜。
- 适用点：可用于道路可行驶区域预训练。
- 官方主页：https://www.bdd100k.com/

## 2. Cityscapes

- 任务：城市街景高质量语义分割。
- 规模：5,000 张精细标注图像 + 2 万张粗标注。
- 适用点：高质量分割基准，可迁移到农村道路。
- 官方主页：https://www.cityscapes-dataset.com/

## 3. KITTI Road

- 任务：道路检测、自动驾驶感知。
- 规模：城市/乡村/高速混合场景。
- 适用点：补充道路边界和复杂光照场景。
- 官方主页：http://www.cvlibs.net/datasets/kitti/

## 4. TWHD（Two-Wheeler Helmet Detection）

- 任务：二轮车与头盔目标检测。
- 适用点：二轮车目标先验，提升农村交通参与者识别。
- 检索关键词：`TWHD dataset`、`two wheeler detection dataset`。

## 5. 国内电动车/摩托车相关开源数据

- 任务：电动车、摩托车、三轮车检测。
- 适用点：适配本地车型与视角。
- 建议渠道：高校实验室公开数据、天池/AI Studio/Kaggle。

## 6. 自采集农村数据（关键）

- 必采场景：土路、村道、田间路、窄路会车点。
- 必采对象：电动车、摩托车、三轮车、行人、动物、路障、坑洼。
- 必采条件：晴天/阴天/黄昏/夜间，顺光/逆光，干燥/积水。

## 7. 推荐组合策略

- 分割：Cityscapes + BDD100K 预训练，农村自采集微调。
- 检测：COCO 预训练权重 + TWHD/本地二轮车数据 + 自采集障碍物数据。
- 验证集：必须包含“纯农村道路”独立测试集，防止只在城市场景上高分。
