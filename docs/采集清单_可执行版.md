# 采集清单（可执行版）

目标：优先提升检测 Recall，重点补齐 `barrier / pedestrian / animal / pothole`，同时提升远距小目标与遮挡场景覆盖。

## 1. 优先级与数量目标（建议增量）

| 优先级 | 类别 | 最小增量（建议） | 理想增量（建议） | 备注 |
|---|---|---:|---:|---|

## 2. 场景清单（必须覆盖）

1. 时间与光照
1.1 清晨与傍晚（低角度逆光）
1.2 正午强光（高反差）
1.3 夜间与弱光（路灯、车灯）

2. 天气与能见度
2.1 小雨与雨后路面反光
2.2 薄雾或扬尘
2.3 风沙与土路起尘

3. 道路与地形
3.1 土路、砂石路、坑洼破损路
3.2 狭窄乡道（会车难）
3.3 临水/临崖边缘（安全敏感）

4. 交通与人群密度
4.1 集市/村口人群聚集
4.2 学校/村委/路口
4.3 牲畜横穿或路边停留

5. 目标尺度与遮挡
5.1 远距小目标（占画面 < 2%）
5.2 半遮挡（树枝、车体、行人群）
5.3 运动模糊（行驶中拍摄）

## 3. 类别细化采集要求

### 3.1 barrier（优先）
建议场景：路桩、石堆、施工围挡、农用工具堆放、路边堆料、倒伏物、锥桶。
要求：尽量包含“部分遮挡”和“远距小目标”。

### 3.2 pedestrian
建议场景：行人群、背对/侧身、穿深色衣物、打伞、低头行走。
要求：包含“夜间路灯”与“逆光轮廓”样本。

### 3.3 animal
建议场景：狗、牛羊、家禽聚集、单只横穿、路边停留。
要求：不同体型、不同颜色、与车辆同框。

### 3.4 pothole
建议场景：大小不一的坑洼、碎裂补丁、积水坑。
要求：光照变化下都清晰可见（阴影/反光）。

### 3.5 two_wheeler / tricycle
建议场景：远距行驶、背影、侧面、载物、多人同车。
要求：与行人、车辆混合场景。

## 4. 采集参数建议（尽量统一）

1. 分辨率：1920x1080 或 1280x720（优先 1080p）
2. 帧率：25-30 FPS（视频）或相机连拍
3. 拍摄高度：约 1.2-1.6m（接近车把/头盔高度）
4. 视角：车道中心视角为主，辅以轻微侧视

## 5. 标注优先级与规范

1. 先标：barrier / pedestrian / animal / pothole
2. 再标：two_wheeler / tricycle
3. 遮挡目标仍需标注可见部分
4. 小目标尽量精确框，避免大框包围背景

## 6. 采集后处理流程（最小步骤）

1. 挑选清晰帧（避免严重模糊）
2. 分类归档（按场景与类别）
3. 标注并复核
4. 统一格式后再训练
