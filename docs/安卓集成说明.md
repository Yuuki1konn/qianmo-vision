# Android 集成说明

## 1. 技术栈

- Kotlin
- CameraX
- TensorFlow Lite
- Android TTS

## 2. 推理流程

1. CameraX 获取 `ImageProxy` 帧。
2. 转换到模型输入尺寸（如 640x640），并做归一化。
3. 分别送入分割模型和检测模型。
4. 对输出做后处理（阈值/NMS）。
5. 将掩码与检测框绘制到预览层。
6. 触发 TTS 告警（如障碍物距离较近或偏离道路）。

## 3. 目录建议

- `android/app/src/main/java/.../camera`：相机采集
- `android/app/src/main/java/.../inference`：模型推理
- `android/app/src/main/java/.../render`：叠加绘制
- `android/app/src/main/java/.../tts`：语音告警
