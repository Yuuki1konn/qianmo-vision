# 用户手册

## 1. 功能简介

本系统用于农村道路场景下的实时辅助识别，支持：
- 道路可行驶区域显示
- 二轮车/行人/动物/路障/坑洼检测
- 语音提醒（危险目标与偏离道路）

## 2. 安装步骤

1. 安装 APK。
2. 打开应用并授予相机与麦克风权限。
3. 在设置中选择模型、置信度阈值与语音开关。

## 3. 使用方式

1. 点击“开始识别”进入相机预览。
2. 绿色半透明区域表示可行驶区域。
3. 检测框显示目标类别与置信度。
4. 出现高风险目标时系统自动语音提示。

## 4. 注意事项

- 夜间低照场景请开启补光或降低速度。
- 雨雾天气可能降低识别稳定性。
- 建议定期更新模型文件以提升效果。
