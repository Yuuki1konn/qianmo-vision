# 技术文档

## 1. 系统组成

- 数据层：公开数据 + 农村自采集数据
- 模型层：U-Net/DeepLabV3+（分割） + YOLOv8（检测）
- 部署层：TFLite FP16 / Dynamic Range + Android CameraX

## 2. 数据流

1. 相机采集帧并预处理（旋转、缩放、归一化）
2. 分割主模型输出道路掩码
3. 检测模型输出目标框
4. 后处理（阈值/形态学/NMS）
5. 可视化叠加与 TTS 告警

## 3. 关键指标

- 分割：mIoU、Dice、Pixel Accuracy
- 检测：mAP@0.5、mAP@0.5:0.95、Precision、Recall
- 性能：FPS、内存占用、电量消耗

## 4. 目录说明

- `scripts/data`：数据处理
- `scripts/train`：训练
- `scripts/eval`：评估
- `scripts/export`：导出与一致性验证
- `android/app`：端侧完整实现（包名 `com.qianmo.ruralvision`）

## 5. 风险与优化方向

- 风险：农村长尾场景多，数据分布偏移明显。
- 优化：持续采集难例，使用蒸馏/剪枝/量化联合优化端侧性能。

## 6. 当前落地结论

- 主分割模型：`relaxed`
- 主部署格式：`TFLite FP16`
- 备用部署格式：`Dynamic Range Quantization TFLite`
- 保守版 `strict` 当前不建议真机实时双跑，保留为离线分析或安全参考。
