# 数据采集与标注规范

## 1. 采集规范

- 分辨率建议：至少 1280x720，帧率 25fps 及以上。
- 采集设备：手机后摄或运动相机，固定于车把或头盔，减少抖动。
- 采集时段：白天、黄昏、夜间；至少各占 20%。
- 天气覆盖：晴天、阴天、雨后路面，尽量包含轻雾。

## 2. 标注工具

- 目标检测：LabelImg、LabelStudio。
- 道路分割：LabelMe、CVAT、LabelStudio。

## 3. 类别定义

- 检测类：`electric_bike`、`motorcycle`、`tricycle`、`pedestrian`、`animal`、`barrier`、`pothole`
- 分割类：`background`、`drivable_area`

## 4. 标注规则

- 检测框：目标完整可见部分尽量贴边，不要过大包围背景。
- 分割掩码：可行驶区域应连续闭合，避免“破洞”与交叉边界。
- 模糊样本：仅在目标可辨时保留，否则剔除。

## 5. 质量检查

- 每 200 张抽检一次，错误率超过 3% 则整批返工。
- 使用可视化脚本叠加检查边界框与掩码。
